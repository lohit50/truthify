# Truthify — AI Fake News Detection

> Paste any headline or article and get an instant credibility verdict — with the
> reasoning behind it.

**Live demo → [truthify-4bud.onrender.com](https://truthify-4bud.onrender.com/)**

---

## What it does

Truthify is an AI-powered misinformation detection platform. Instead of a plain
"true / false" label, it explains *why* a claim looks credible or suspicious, so
the reader can judge for themselves.

- **Instant credibility verdict** on any headline or article
- **Reasoning included** — not a black box
- **Text and image analysis** using modern NLP models
- Clean, focused UI built for fast checking

## Tech

React · Python · NLP models · REST API

## Why I built it

Misinformation spreads faster than corrections. A tool that shows its reasoning
teaches people *how* to evaluate a source, which lasts longer than any single
fact-check.
